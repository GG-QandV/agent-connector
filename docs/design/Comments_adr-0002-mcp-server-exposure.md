Готов ADR-0002. Ключевая идея, ради которой всё построено: **MCP-сервер повторяет ровно тот же структурный паттерн**, что уже доказан в двух существующих серверах — тонкий mapper, без собственной копии бизнес-логики.

## Как избежать тройного дублирования

Таблица RACI в документе фиксирует главное правило: **task lifecycle, idempotency и concurrency limits живут только в `AdapterCore`**, каждый protocol crate (`a2a-server`, `acp-runtime`, новый `mcp-server`) отвечает только за свой wire-формат и streaming-адаптацию.
